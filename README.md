# Sculpt Me v1.4 workout test
Deploy all files in this ZIP to the repository root (including workout-upgrade.js).

Workout test: animated anime-style SVG character appears for all warm-up, workout and cool-down steps; each step has a specific movement label and written instructions. This is a lightweight pose/movement prototype, NOT a fully anatomically accurate animation for every exercise. The original Squat/Glute Bridge GIF assets remain embedded in index.html but are not used by the new workout guide.

Set logic: four warm-up steps, eight exercises in Set 1/2, eight exercises in Set 2/2, four cool-down steps. Set changes only after all eight exercises in Set 1. The session is 15/20/30/45 minutes, with 30 default; timers auto advance with 3-2-1 countdowns. Each step uses its full allocated time, so countdowns are extra transition time.

The old app's nutrition, grocery, water, icons and wardrobe are retained. New workout preferences, rest days and streak are saved locally. Treatment-Aware defaults OFF and should not replace clinic instructions. The current illustration is a simplified animated guide, not the final unique exercise animation library. Test on your device before replacing a production app.
