# Sculpt Me v1.3 — Personalized Workout MVP
Upload the seven deploy files to the root of your existing GitHub repo and commit. Vercel deploys automatically if connected.

New: multiple workout styles, 15/20/30/45-minute sessions (30 default), intensity selection (Moderate default), two custom rest days, schedule-based streak, Free Workout and Challenge selection, 3-2-1 countdown, and automatic Set 1/2 -> Set 2/2 progression. Treatment-Aware OFF by default.

Existing meals, grocery, hydration, icon, and wardrobe assets are retained.

Limitations: only Squat and Glute Bridge have animated demos; new exercises use text instructions. Data stays in browser localStorage, not synced. Changing rest days may reinterpret prior schedule. This MVP does not replace clinic exercise guidance during IVF treatment.
